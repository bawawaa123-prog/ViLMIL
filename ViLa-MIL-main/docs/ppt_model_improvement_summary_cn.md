# ViLa-MIL 改进现状总结（原理与动机版）

本稿只从原理与动机角度讲两点改进，不展开代码文件清单，适合直接用于PPT讲解。

---

## 改进点1：CLIP 替换为 BiomedCLIP

### 1. 动机（为什么必须改）
- 原始 CLIP 的语义空间主要来自自然图像和通用文本，面对病理术语时容易“语义偏移”。
- 在病理分类任务中，文本提示是分类决策的重要约束；如果文本编码器不懂医学语义，图文对齐会被拉低。
- 因此，第一步优先做“语义底座升级”，先把文本理解能力换成医学领域更强的 BiomedCLIP。

### 2. 原理（它为什么可能有效）
- 双模态模型的核心是把图像特征和文本特征映射到同一语义空间。
- BiomedCLIP 在医学图文上预训练，意味着它的文本嵌入更贴近病理描述分布。
- 当文本特征更“医学化”时，图像与文本的相似度计算会更可靠，从而提升 logits 融合质量。

### 3. 对原链路的影响（讲逻辑，不讲实现细节）
1. 输入数据与MIL框架不变：仍是双尺度特征聚合。
2. 变化发生在“文本语义编码层”：从通用语义换成医学语义。
3. 分类头不变，但输入到分类头的图文对齐信号质量提升。

### 4. 阶段性结果（5折均值）
- 基线：Test AUC 0.9050 / ACC 0.8704 / F1 0.8013
- 替换后：Test AUC 0.9672 / ACC 0.9225 / F1 0.9160

结论：改进点1属于“底层语义能力升级”，收益确定且幅度明显，是当前最稳固的增益来源。

## 改进点2：RAG增强路线（分三步递进）

这一部分建议你在PPT中明确讲成三步，不要一次性把“RAG”打包成一个黑盒。三步分别是：

1. 第一步：检索增强动态提示（先检索，不生成）
2. 第二步：视觉条件化提示（VCP，做轻量条件化微调）
3. 第三步：RAG+LLM重写（先检索再生成）

这样讲的好处是：评审能看懂你不是“直接上大模型”，而是在做可控、可解释、可消融的分层升级。

### 第一步：检索增强动态提示（Dynamic Retrieval Prompt）

#### 动机
- 静态提示词对所有样本一视同仁，无法体现每张slide的形态差异。
- 在病理任务里，样本异质性高，提示需要“按样本变化”。

#### 原理
- 把每个类别的候选描述做成句子池。
- 用当前slide的视觉表征与句子池做相似度检索，选出最相关的Top-K句子。
- 用加权方式形成该slide的动态提示表示，再与静态提示做融合。

#### 修改内容（讲概念层）
- 新增“按类句子池 + Top-K检索 + 温度加权 + 动静融合”机制。
- 训练和评估都可开启同一检索逻辑，保证链路一致。

#### 影响
- 优点：提示从全局模板变为样本条件化提示，解释性增强。
- 风险：检索质量受句子池质量影响，句子池若噪声多会引入干扰。

### 第二步：视觉条件化提示（VCP）

#### 动机
- 仅检索仍然属于离散选择，缺乏连续可学习的微调能力。
- 希望让视觉上下文能进一步细调文本提示，而不是只做“选句子”。

#### 原理
- 通过轻量参数模块，从当前视觉特征预测一个文本偏移量。
- 将偏移量加到文本特征上，相当于对提示做条件化校准。
- 本质是把“硬检索”补充为“连续微调”。

#### 修改内容（讲概念层）
- 新增视觉到文本偏移的条件化模块。
- 增加按epoch启停策略，避免训练早期扰动过大。

#### 影响
- 优点：可学习的细粒度对齐能力增强。
- 风险：参数设置不当容易引起训练不稳定，因此通常作为第二阶段对照项。

### 第三步：RAG + LLM 重写（Retrieval-Augmented Generation）

#### 动机
- 第一步和第二步主要在向量层面增强，语义表达能力仍受模板限制。
- 希望利用LLM把检索证据组织成更自然、更完整的slide级描述。

#### 原理
- 先检索：从当前slide得到类别相关证据文本。
- 再生成：把证据输入LLM，生成低倍/高倍两组类别提示。
- 最后编码：将生成提示编码回文本特征参与分类。

#### 修改内容（讲概念层）
- 增加offline/online/hybrid三种工作模式。
- 采用缓存机制将生成结果固化，训练阶段优先离线读取。
- 增加失败回退与重试机制，保障训练可持续运行。

#### 影响
- 优点：语义表达能力最强，理论上最具上限。
- 风险：在线生成存在随机性与服务波动，必须通过离线缓存控制实验稳定性。

### 三步方案的阶段性结果如何讲
- 当前最稳定且收益确定的仍是“改进点1（BiomedCLIP底座升级）”。
- 在其基础上，三步RAG路线已经完成工程闭环：
  - 第一步提供检索证据
  - 第二步提供条件化微调
  - 第三步提供语义重写能力
- 现阶段结果说明：方法方向成立，但第二步和第三步仍处于参数精调期。

可用于结果页的对比数字（5折均值）：
- BiomedCLIP（无RAG三步增强）：Test AUC 0.9672 / ACC 0.9225 / F1 0.9160
- BiomedCLIP + 当前RAG阶段方案：Test AUC 0.9613 / ACC 0.9132 / F1 0.9019

结论建议：
- 三步RAG方案带来的是“能力上限扩展”和“样本条件化语义增强”。
- 当前尚未超过改进点1最佳值，不代表路线无效，而是说明第三阶段方法需要继续做质量控制与参数调优。

## 你的PPT如何讲（只讲原理与动机）

### 第一部分：模型改进现状（两页）
- 第1页：改进点1
  - 讲法：问题是什么 -> 为什么 BiomedCLIP 合理 -> 链路哪里被增强
- 第2页：改进点2
  - 讲法：三步路线依次讲
  - 第一步检索增强（为什么先做）
  - 第二步VCP校准（为什么再做）
  - 第三步RAG重写（为什么最后做）

### 第二部分：阶段性结果（两页）
- 第3页：基线 vs 改进点1（证明第一点有效）
- 第4页：改进点1 vs 改进点1+改进点2（证明第二点仍在优化期）

### 每页建议固定结构
- 上半区：动机与原理（2-3条）
- 下半区：结果数字（AUC/ACC/F1）
- 页尾：一句结论（要有判断，不要中性描述）

## 可直接复用的总结句
本阶段改进体现出清晰的递进逻辑：先通过 BiomedCLIP 完成医学语义底座升级，再通过“检索增强 -> 视觉条件化 -> RAG重写”三步路线逐层增强提示能力；当前三步方案已具备方法合理性与工程可复现性，正在进入效果精调阶段。
